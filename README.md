# Front-End Portfolio

A responsive portfolio website for showcasing practical front-end projects.

## Featured work

- [FreshFind](https://github.com/azwinearnest01-rgb/fresh-find-website.) — local farmers-market directory
- [Bakez Bitz](https://github.com/azwinearnest01-rgb/Bakery-website-) — interactive bakery storefront

## Technology

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Responsive and accessible design

## Run locally

Open `index.html` in a modern browser. No build step is required.
